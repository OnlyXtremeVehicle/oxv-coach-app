## Vérification adversariale (avant commit)

3 lentilles (APIs natives / intégration router / doctrine-tokens-a11y) : **28 findings, tous corrigés** — dont 7 majeurs :
1. `(app2)` sans garde d'auth ni de build (deep links prod) → gardes ajoutés.
2. Sheet piégeant VoiceOver (modal sans échappement) → onAccessibilityEscape + poignée fermante.
3. `dialDisplayValue` fabriquait un « 0 » sur valeur absente → « — » + `Dial` nullable (règle données réelles).
4. Chip : état actif invisible aux lecteurs d'écran → `accessibilityState.selected`.
5. Parallaxe HeroPhoto fausse hors tête de scroll → `parallaxOffset` + bleed.
6. Collision de route `/club` v1↔v2 → neutralisée par la garde de build (résolution documentée ; la route v2 ne prime jamais en prod).
7. Zone morte tactile du bouton central (~10 px hors bounds) → bounds étendus (`TAB_BAR_OVERHANG`), hauteur visuelle inchangée.
Également : hook reduce-motion asynchrone (1re frame animée malgré le réglage) → hook synchrone ; blur Android inexistant par défaut → repli opaque déterministe unifié (header/TabBar/Sheet), iOS garde le vrai blur ; « J-x » figé en arrière-plan → refresh AppState ; accent des millièmes qui débordait sur l'unité ; + 15 correctifs de robustesse (timers, deps d'effets, gestes, hitSlop, contrastes).
Le rapport confirme aussi ce qui **tient** : workletisation correcte partout (plugin vérifié dans reanimated 3.10.1), Skia 1.2.3 conforme, zéro division par zéro, zéro fuite de boucle, périmètre git exact, doctrine et tokens irréprochables (or confiné, QDI données seules, zéro couleur en dur, textes vouvoyés sans emoji).
