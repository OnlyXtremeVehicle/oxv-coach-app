## Vérification adversariale (5 dim × 3 lentilles) — 1 survivant + 3 « dropped » RÉELS
La vérif a rendu 1 survivant ; mais 3 findings « dropped » (1/3) étaient de VRAIS
bugs — les lentilles réfutantes ont **cru le type TS `number`** alors que PostgREST
rend les colonnes `numeric` en **STRING** au runtime (le service a d'ailleurs un
helper `num()` qui le prouve). Corrigés (commit de fixes) :

1. **[MAJEUR doctrine — survivant]** Comparateur : `B_COLOR = heritage.gold`.
   L'or est l'étalon record/prestige app-wide (`tokens.ts` « jamais un chrome
   générique ») → en mode Ami l'ami portait TOUJOURS la couleur « référence » et
   le pilote un accent ordinaire = hiérarchie implicite sur un écran sans gagnant.
   **Fix** : B = `text.hi` (crème neutre), deux teintes de même poids ; docstrings
   alignées.
2. **[CRITIQUE crash]** `session/[id].tsx` : `session.distance_km.toFixed()` sur une
   string → crash au rendu du pivot. **Fix** : `Number(distance_km).toFixed()`.
3. **[MAJEUR logique]** `comparer.tsx` : `l.duration_seconds < best.duration_seconds`
   comparait deux STRINGS lexicographiquement (« 9.5 » < « 10.2 » faux) → **mauvais
   tour de référence**. **Fix** : `Number(...) < Number(...)`.
4. **[MAJEUR crash Skia]** `session/[id].tsx` ChannelsChart : garde `speed<2 && brake<2`
   (ET) → une séance GPS-only (vitesse mais pas de g-force) rendait `<Path path="" />`
   → « Invalid path ». **Fix** : peindre chaque canal SEULEMENT si sa chaîne est non
   vide. Les autres Path (corner-evolution, heatmap, comparer, courbe saison) étaient
   déjà gardés / SkPath-objets.

**Reste minor consigné** (dropped 1/3, non bloquant) : saison — la régularité peut
être calculée sur un lot de tours silencieusement incomplet (fan-out non strict) ;
à durcir avec `strict:true` (suivi).
