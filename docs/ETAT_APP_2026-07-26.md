## 4. Le direct — transport

Trois topics Realtime, tous **refcomptés** (`liveSessionService`) :

- `live:roster:<coachId>` — présence, un roster par coach consenti
- `live:session:<id>` — trames télémétriques + événement biométrique (canal coach)
- `live:board:<id>` — tableau de marche (LIVE-B), payload filtré par `stripHealth`

Le refcomptage est obligatoire : supabase-js déduplique les canaux par topic, donc
sans comptage la fermeture d'un écran arrache le canal d'un autre. Verrouillé par
9 tests, validés par mutation.
