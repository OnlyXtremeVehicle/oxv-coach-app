Guide d'intégration des écrans

Six écrans livrés en HTML autonome. Chacun est une référence visuelle d'un écran de l'app : tu ne recodes que le rendu, la logique (données, navigation, RLS, doctrine) reste intacte. Ce guide donne, écran par écran, la cible .tsx, les tokens, le kit de composants, la traduction Skia, les états et le câblage de navigation.

2 · Écarts assumés vs handoff d'origine

À valider avant réintégration
  • Typographie changée (sur ta demande) : Rajdhani pour titres + chiffres héros, JetBrains Mono pour données/labels, au lieu de Geist / Geist Mono. Instrument Serif conservé pour la ligne-miroir et l'éditorial. → Ajouter les 2 familles via expo-font. Si tu refuses, le mapping reste identique, seule la police retombe sur Geist.
  • Radius technique : cartes passées à 6px (langage HUD) au lieu du xl arrondi. Choix esthétique nouvelle-génération.
  • Palette par pilier/phase appliquée (§4). Le Freinage utilise le rouge-donnée #E63946 comme couleur de pilier — distinct du rouge-marque #C8102E (REC / coach), qui n'est jamais employé ici.

4 · Écran par écran

A2 · signature.tsx
Signature / QDI

Roi : QDI composite 73/100 en or, dans un tachymètre HUD (arc 270° gradué). Kit : AppBar · Cockpit panel · QdiRadar recoloré par pilier · MeterBar (barres piliers) · SectionLabel.

Viz → Skia : jauge = Path.addArc + trim piloté par un progress Reanimated ; radar = polygone Skia (fill or translucide + stroke), réf. médiane en DashPathEffect, réf. record en liseré clair ; barres = Rect animés.

Interactions : tap pilier → accordéon (grandeur mesurée + écart au record) ; toggles Médiane / Record. États : nominal · vide · chargement · hors-ligne. Nav : depuis le hub Progression ; retour AppBar.

A5 · virage.tsx
Détail virage

Roi : vitesse à la corde 118 km/h en or (minimum du profil). Numéro de virage en heritageGold. Kit : AppBar · Cockpit panel · MeterBar.

Viz → Skia : profil de vitesse = Path lissé qui se dessine (clip progressif) ; halo = Paint.maskFilter blur ; aire = gradient vertical ; 3 bandes de phase = Rect translucides bleu/ambre/vert ; point de corde ambre pulsant.

Interactions : tap phase → cadrage de la bande + détail. Nav : ouvert depuis la feuille basse de carte.tsx et depuis Data Lab.

A2 · bilan.tsx
Bilan — arbitrage ⚠ tranché

Décision : la jauge de régularité domine (écart-type 0,34 s, GaugeInstrument plein format) ; le meilleur tour passe en carte secondaire (chrono mono, plus petit) — un seul grand chiffre roi. Kit : GaugeInstrument · Card · bande de dispersion (MeterBar signée).

Viz → Skia : dispersion tour-à-tour = barres Rect signées autour du zéro + bande ±σ or. Transparence : bloc source / angles morts obligatoire en bas. États : 4.

A3 · data-lab.tsx
Data Lab

Structure : bannière confiance de lecture en tête (barre verte + métriques), puis index neutre de 7 vues — titres en crème, jamais or. Badge PAS DE DONNÉES sur les vues vides (désactivées). Action Export CSV dans l'AppBar (bouton ghost). Kit : AppBar+action · Card lignes · Pastille de statut.

Nav : chaque ligne route vers sa vue — unifiée→data-lab-canvas · carte · virage · tours · signature · comparer · heatmap. Vues sans donnée : non cliquables.

A4 · carte.tsx
Carte circuit

Structure : tracé plein cadre. 3 couches activables (LayerToggle) : Tracé · Vitesse · Marges. Tap virage → CornerPanel (feuille basse : n° heritageGold, vitesse corde or, marge à la corde). Marge serrée = ambre #F2792B, jamais rouge.

Viz → Skia : ruban = Path Catmull-Rom (lit large + ligne de course or) ; couche Vitesse = segments colorés par courbure (bleu→ambre→or) ; couche Marges = Circle ambre dimensionnés par serrage ; start/finish = Rect ; marqueurs = Circle + n° heritageGold. Nav : CornerPanel « Ouvrir le détail » → virage.tsx.

5 · Pattern d'animation

Côté HTML, chaque entrée est animée (chiffres qui comptent 0→valeur, jauges/tracés qui se dessinent, barres qui se remplissent) via requestAnimationFrame, doublé d'un repli setTimeout qui fixe l'état final même si l'onglet est en arrière-plan (rAF y est gelé). En RN, ce repli est inutile : utilise un useSharedValue(0) + withTiming(1, {duration:1150}) dans un useEffect de montage. L'état au repos = la valeur finale ; l'animation n'est qu'un plus, non bloquant.

6 · Checklist doctrine à repasser

  • Or = donnée uniquement (jauge, chiffre, points, barres, courbe) — jamais décor.
  • Un seul grand chiffre roi par écran.
  • Rouge-pilier #E63946 ≠ rouge-marque #C8102E ; aucun rouge sur une perf globale.
  • Pastilles de statut et eyebrows jamais or ; Instrument Serif jamais un chiffre.
  • EmptyState doux, jamais culpabilisant ; bloc méthode / transparence présent sur les écrans data.
  • Références (médiane, record) self-only — jamais un autre pilote.
  • Fonts Rajdhani + JetBrains Mono ajoutées, ou repli Geist validé.
